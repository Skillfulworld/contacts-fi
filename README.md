# ContactsFi 📱

ContactsFi is a crypto contacts application for the Arc Network.

The app provides a clean, mobile-first interface to manage your crypto contacts, view wallet details, and handle transactions, inspired by the familiar Android Contacts experience.

## Features
- **Contacts List:** Easily manage your crypto contacts with a familiar interface.
- **Contact Details:** View wallet health, recent transactions, and notes.
- **Add/Edit Contacts & Wallets:** Simple forms for managing your address book.
- **Settings:** Customize your experience.
